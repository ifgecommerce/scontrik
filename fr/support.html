Assistance

Besoin d’aide avec Scontrik ? Écrivez à info@ifgecommerce.com en indiquant votre modèle d’iPhone, votre version d’iOS et la version de l’app (Réglages → Version). Nous répondons dès que possible.

Questions fréquentes

Que signifie « Vérifié » ?

La valeur a été trouvée écrite sur votre ticket. Si l’app ne la trouve pas, elle affiche « À vérifier » au lieu de deviner.

Comment garder ma propre copie de mes données ?

Réglages → Exporter toutes les données. Vous obtenez un fichier ZIP avec vos fichiers originaux, ainsi que des fichiers JSON et CSV. L’export est gratuit.

Comment supprimer un élément ?

Ouvrez l’achat, touchez le menu et choisissez Supprimer. Pour tout effacer : Réglages → Supprimer toutes les données.

Mon rappel de garantie n’est pas arrivé

Vérifiez que les notifications sont activées pour Scontrik (Réglages d’iOS → Notifications) et que le rappel apparaît comme actif sur l’achat.

Comment annuler mon abonnement ?

Dans les réglages de votre identifiant Apple → Abonnements. Vous pouvez aussi utiliser Réglages → Gérer l’abonnement dans l’app.

J’ai acheté Pro sur un autre appareil

Ouvrez Réglages → Restaurer les achats.
